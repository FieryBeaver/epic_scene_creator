# Дошка сцен — посібник

Інструмент для епіку на кілька столів: усі сцени підземелля на одній мапі,
хто яку веде, що в ній небезпечне, що перекрито — і хто саме тримає рішення.

Сервера немає. Дошка живе у вкладці браузера. **Експорт JSON** — це кнопка
«зберегти», **Імпорт JSON** — «відкрити».

## Перші п'ять хвилин

1. Відкрийте <https://fierybeaver.github.io/epic_scene_creator/>.
2. Натисніть **Демо-розкладка** — з'явиться готове підземелля з 12 сцен.
   Це найшвидший спосіб побачити, як усе працює. Далі — **Очистити** і почніть
   своє.
3. **+ Сцена** або подвійний клік по порожньому полю — нова сцена.
4. **🔗 З'єднати**, потім клік по двох сценах — прохід між ними.
5. Клік по сцені — праворуч відкриється її картка. Заповнюйте.
6. **Експорт JSON** наприкінці. Без цього нічого не збережеться.

## Три поняття, на яких тримається дошка

**Небезпека (☠)** — те, що сцена робить постійно і що не вирішується
всередині неї. Орди нежиті, токсичний слиз, привиди. У полі
*«Вимикається у сцені»* вкажіть, де саме лежить рішення — і та сцена одразу
побачить у себе «↩ ця сцена розв'язує».

**Блок (⛔)** — зачинені двері в широкому сенсі. Перекривають або кімнату,
або прохід із цієї сцени. Ключ завжди в іншій сцені.

**Івент (⚡)** — подія, яку запускають самі гравці. Може відкрити або закрити
конкретний прохід. Галочка *«спрацював»* застосовує ефект одразу: прохід
змінює стан на дошці.

Разом вони і є сенс дошки: коли за столом 1 питають «а це взагалі можна
прибрати?», ДМ бачить відповідь і те, кому дзвонити.

**Зв'язок видно з обох боків.** Якщо ви вказали, що небезпека чи блок
вимикається у конкретній кімнаті іншої сцени, то й у тій кімнаті з'явиться
зворотне посилання: «↩ Тут рішення для: ☠ Орди нежиті · Гнилі зали». На дошці
така кімната позначена стрілкою ↩. ДМ, який веде цю сцену, не мусить
здогадуватися, що його непримітна комора комусь критично потрібна.

## Сцена

| Поле | Навіщо |
|---|---|
| Назва, ДМ, колір | Підпис картки й ліва смуга. |
| Нотатки | Довільний текст, видно в режимі перегляду. |
| Кімнати (▣ / ◈) | Зала, коридор, ділянка. Може містити скарб, гробницю бога, скелетний ключ, посилання на баттлмапу. |
| Небезпеки (☠) | Рівень 1–4 фарбує чип на картці. Галочка *активна* знімається під час гри. |
| Блоки (⛔) | Ціль — кімната або прохід цієї ж сцени. |
| Івенти (⚡) | Тригер, наслідок, вплив на прохід. |
| Лічильники | Хвилі, раунди, HP союзників. Кнопки +/− працюють просто на картці. |
| Токени | Хто зараз тут. |

## Проходи

Клік по підпису переходу на дошці відкриває його картку.

- **Тип** — двосторонній або однобокий (стрілка на лінії).
- **Боки** — «виходить на схід», «входить із заходу». Якщо не вказати, лінія
  сама шукає найкоротший шлях; якщо вказати — тримається вказаного боку.
  Це єдиний спосіб акуратно розвести кілька проходів між тими самими сценами.
- **Хвилин на перехід** — показується на підписі.
- **Прохід відкритий** — знята галочка малює лінію пунктиром.
- Свої лічильники: «проходів», «хвилин витрачено».

## Кімнати, гробниці та ключі

Кімната — частина сцени. У кімнаті може лежати скарб і будь-який елемент зі
**списків**. За замовчуванням списків два: *Гробниці богів* (дев'ять) і
*Скелетні ключі* (п'ять).

Головне правило: **один елемент лежить рівно в одній кімнаті на всій дошці**.
Якщо перекласти гробницю Моа в іншу сцену, зі старої вона зникне сама. Вкладка
списку ліворуч показує рахунок — `7/9` означає, що дві гробниці ще не
розставлені.

Свій список (артефакти, NPC, печатки) — кнопка **＋** у смузі вкладок.

## Токени

Партії, розвідгрупи, союзники, боси, що прорвались крізь Ворота. Токен
перетягується мишею: зі сцени на сцену або на підпис проходу — «група зараз
у коридорі». Перетягнути на порожнє поле — зняти з дошки.

## Два режими

**Режим редагування** — усе редагується.

**Режим перегляду** (кнопка 👁 або клавіша `v`) — інструменти авторства
зникають, картка сцени перетворюється на брифінг: переходи, кімнати,
небезпеки, блоки, івенти, «ця сцена розв'язує». Кожне посилання на іншу сцену
— кнопка, клік переносить туди. Лічильники й токени лишаються робочими: це
стан гри, а не редагування.

Це режим для столу під час сесії.

## Керування

| | |
|---|---|
| Колесо миші | Зум до курсора |
| Тягнути фон | Панорама |
| Тягнути заголовок сцени | Пересунути сцену (крок 8 px) |
| Подвійний клік по полю | Нова сцена тут |
| `f` | Вмістити все |
| `n` | Нова сцена в центрі екрана |
| `v` | Перемкнути режим |
| `Delete` | Видалити вибрану сцену або прохід |
| `Esc` | Скасувати з'єднання / зняти виділення |
| Тягнути межу панелі | Змінити ширину |
| Подвійний клік по межі | Згорнути панель |

Ширини панелей зберігаються у файлі дошки.

## Спільна дошка на кілька столів

Якщо ДМів кілька, дошку можна під'єднати до приватного репозиторію GitHub —
і всі пристрої бачитимуть одне й те саме. Кнопка стану у верхній панелі
показує, чи все синхронізовано; клік по ній відкриває налаштування.

Головне, що варто знати за столом:

- Кожна **сцена, перехід, токен і список** версіонуються окремо. Два ДМи, які
  ведуть різні сцени, не заважають одне одному взагалі.
- Якщо двоє редагують **ту саму сцену**, перемагає той, хто зберіг пізніше —
  і лише для цієї сцени. Той, чию зміну перезаписано, побачить повідомлення.
- **Без мережі** все працює далі: правки збережуться і поїдуть, коли зв'язок
  повернеться.

Покрокове налаштування — у [SYNC.md](SYNC.md).

## Збереження

Дошка автоматично зберігається в цьому браузері через мить після кожної зміни
і відновлюється при наступному відкритті. Це страховка від закритої вкладки,
а не заміна експорту.

Повноцінне збереження — **Експорт JSON**. Файл можна покласти в git поруч із
нотатками кампанії, надіслати іншому ДМ, відкрити на іншій машині.

Якщо є незбережені зміни, браузер перепитає перед закриттям вкладки. Це не
заміна експорту — це нагадування.

Формат файлу описано в [DATA_FORMAT.md](DATA_FORMAT.md).
